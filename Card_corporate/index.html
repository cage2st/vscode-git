엑셀에서 회사 메모까지.

사용 내역을 불러오면, 엑셀의 이름을 메모에 입력할 수 있는 화면을 만듭니다.

01 엑셀 불러오기02 메모 입력 만들기03 최종 화면

STEP 01

엑셀 파일 불러오기

날짜 · 금액 · 이름 · 거래처 열이 있는 XLSX 파일을 선택하세요.

STEP 02

메모 입력 만들기

선택한 월의 이름과 거래 내역으로 입력 도구를 만듭니다.

주소를 넣으면 최종 화면에서 해당 카드 페이지를 바로 열 수 있습니다.

엑셀 파일을 선택해 주세요.

    불러온 사용 내역

    날짜금액이름 → 메모거래처
    생성 완료

    회사 카드 페이지 열기 ↗최종 화면 HTML 다운로드

    1. 북마크 주소 복사 버튼을 누릅니다.
    2. 크롬에서 Ctrl+Shift+O → 오른쪽 위 메뉴 → 새 북마크 추가를 선택합니다.
    3. 이름은 ‘회사 메모 입력’, URL에는 복사한 주소 전체를 붙여넣고 저장합니다.
    4. 회사 카드 상세 창에서 휴근식대 → 전체 적용을 진행합니다. 상단 메모는 비워 두세요.
    5. Ctrl+Shift+B로 북마크바를 표시한 뒤 등록한 북마크를 클릭합니다. 입력 결과를 확인하고 직접 저장하세요.

    링크를 회사 페이지 안으로 드래그하지 마세요. 등록한 북마크를 클릭해서 실행합니다.

    복사가 안 되면 주소 직접 선택

    메모 입력 대상

    날짜금액이름 → 메모거래처
    파일은 브라우저 안에서 처리됩니다. 매월 새 엑셀을 불러와 입력 도구를 만들어 주세요.
