# 작업 기록

## 요청 및 구현

새 프로젝트 위치: `/home/cage/projects/Global_CS/Card_corporate`

사용 흐름:
1. 엑셀 파일 불러오기
2. 메모 입력 만들기
3. 최종 화면 표시

기존 8월 회사 메모 입력 페이지를 결과 화면 참고 자료로 사용했다. 회사 HTML을 추가로 업로드하지 않고 엑셀만으로 입력 도구를 생성한다.

## 현재 기능

- XLSX에서 날짜·금액·이름·거래처 읽기
- 시트 및 대상 월 선택, 내역 미리보기
- 회사 카드 상세 URL 선택 입력
- 북마크 주소 생성 및 복사
- 최종 화면을 독립 HTML 파일로 다운로드
- 회사 화면에서 실행 시 청구월·날짜·금액·거래처 확인
- 거래처 표기가 다르면 날짜·금액이 유일하게 일치하는 거래에 대해 확인 요청
- 누락·중복 거래 차단, 기존 메모 교체 전 확인
- 휴근식대 적용 여부 확인 후 메모 입력
- 저장 및 결재 제출은 사용자가 직접 수행

## 실행

```bash
python3 /home/cage/projects/Global_CS/Card_corporate/start.py
```

크롬 주소: http://localhost:8770/

이미 서버가 실행 중이면 주소만 열면 된다.

## 주요 파일

- index.html: 3단계 홈페이지
- app.js: 엑셀 불러오기, 미리보기, 결과 화면 및 다운로드
- excel-core.js: 엑셀 파싱
- memo.js: 회사 거래 대조 및 북마크 생성
- monthly-core.js: 회사 화면 읽기 및 메모 입력
- style.css: 화면 스타일
- start.py: 로컬 서버
- vendor/: ExcelJS 및 라이선스
- tests/browser.cjs: 브라우저 통합 테스트
- README.md: 사용 안내
