# 법인카드 메모

실행: `python3 /home/cage/projects/Global_CS/Card_corporate/start.py`

크롬에서 http://localhost:8770/ 를 엽니다.

1. 날짜·금액·이름·거래처 열이 있는 XLSX를 선택합니다. 여러 월이 있으면 대상 월을 선택합니다.
2. 메모 입력 만들기를 누릅니다. 회사 카드 상세 주소는 선택 사항입니다.
3. 최종 화면에서 북마크 주소를 복사해 크롬 북마크에 등록합니다. 최종 화면을 HTML로 다운로드해 보관할 수도 있습니다.
4. 회사 카드 상세 페이지에서 휴근식대를 전체 적용하고 등록한 북마크를 실행합니다. 결과를 확인한 뒤 직접 저장합니다.

회사 HTML 업로드는 필요하지 않습니다. 입력 도구는 실행 시 회사 거래를 대조합니다. 거래가 없거나 중복이면 입력을 중단하며, 날짜·금액만 같고 상호가 다르면 확인을 요청합니다. 기존 메모가 있으면 변경 전·후 이름을 보여주고 확인합니다. 엑셀의 유효하지 않은 행은 수정 후 다시 불러와야 합니다.

서버는 Python 표준 라이브러리만 사용합니다. ExcelJS는 vendor에 포함되어 있으며 해당 라이선스가 함께 제공됩니다. 파일 내용은 외부로 전송하지 않습니다.
