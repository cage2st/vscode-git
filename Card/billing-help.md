# 엑셀 → 회사 법인카드 메모

1. `python3 Card/start.py`로 실행한 뒤 Chrome에서 http://localhost:8765 를 엽니다. 이미 실행 중이면 재실행하지 않아도 됩니다.
2. 해당 월 사용 내역 **XLSX**를 선택합니다. 날짜·금액·이름·거래처 열이 있는 시트를 자동으로 찾습니다. 시트와 대상 월을 선택할 수 있습니다. 기존 08월 정리 엑셀도 그대로 지원합니다.
3. 회사의 해당 카드 상세 창에서 Ctrl+S로 저장한 HTML을 선택합니다. 원본 주소의 카드 ID와 청구월 ID, 상세 제목, 거래 표를 읽습니다.
4. 날짜·금액·거래처가 같은 거래는 자동 연결합니다. 상호 표기가 다르면 같은 날짜·금액 후보 중 회사 거래를 선택하고 거래 확인을 체크합니다. 중복 연결은 입력 대상이 될 수 없습니다.
5. **메모 입력 도구 만들기**를 누르고 건수를 확인합니다. 미확인 거래나 읽지 못한 엑셀 행이 있으면 제외 건수를 알립니다.
6. **북마크 주소 복사**를 누릅니다. Chrome/Edge의 Ctrl+Shift+O → 메뉴 → 새 북마크 추가(새 즐겨찾기 추가)에서 이름은 ‘법인카드 메모 입력’, URL에는 복사한 주소 전체를 넣습니다. 기존 북마크를 쓰면 URL을 새 주소로 교체합니다.
7. 회사 상세 창에서 휴근식대 → 전체 적용을 먼저 진행합니다. 상단 메모는 비워 둡니다. Ctrl+Shift+B로 북마크바를 표시하고 등록한 북마크를 클릭합니다. 회사 페이지 안으로 드래그하지 않습니다.
8. 기존 메모가 있으면 변경 전 내용과 엑셀의 이름을 표시합니다. 확인을 누른 경우에만 교체합니다. 결과와 영수증 첨부를 확인한 뒤 회사 화면에서 직접 저장·결재 제출합니다.

매월 새 엑셀과 새 회사 HTML을 불러와 북마크 URL을 갱신합니다. 특정 월이나 카드 번호는 고정되어 있지 않습니다. 엑셀의 이름·금액은 수정하지 않습니다. 회사 탭에서 실행할 때 카드·청구월·거래 내용과 기존 메모를 다시 검증합니다.

파일 처리는 이 브라우저에서 진행하며 외부로 전송하지 않습니다. 저장한 회사 HTML의 스크립트는 실행하지 않습니다. 일반 웹페이지에서는 로그인된 다른 회사 탭을 직접 조작할 수 없어 회사 페이지에서 북마크를 실행하는 방식입니다. 회사 보안 정책이 북마크를 차단하면 실행할 수 없습니다.

수식 셀은 엑셀에 저장된 계산 결과를 읽으며 재계산하지 않습니다. 결과가 없는 셀이나 잘못된 날짜·금액은 오류로 표시합니다. 합계 행은 집계 대상에서 제외합니다. 지원 헤더 예: 날짜/이용일자/사용일, 금액/매입금액/금액(카드 결제액), 이름/이름(파일명)/사용자이름, 거래처/가맹점명.

개발 검증: Card 폴더에서 npm install 후 npm test. 브라우저 검증: Playwright Chromium 설치 및 서버 실행 후 npm run test:browser. 실제 로그인된 회사 사이트의 저장·결재를 실행하는 테스트는 하지 않습니다.

기존 영수증 폴더 입력 화면은 receipt-index.html에 보관했습니다. 새 화면은 index.html입니다.
