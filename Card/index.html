    입력 도구 HTML 다운로드

    1. 북마크 주소 복사를 누릅니다.
    2. Chrome/Edge에서 Ctrl+Shift+O → 메뉴 → 새 북마크 추가(새 즐겨찾기 추가)를 선택합니다.
    3. 이름은 ‘법인카드 메모 입력’, URL에는 복사한 주소 전체를 붙여넣습니다. 기존 북마크가 있다면 URL을 교체합니다.
    4. 회사 상세 창에서 휴근식대 → 전체 적용을 먼저 누르고, Ctrl+Shift+B로 북마크바를 표시한 뒤 등록한 북마크를 클릭합니다.

    회사 페이지 안으로 드래그하지 마세요. 이름 입력 결과와 영수증 첨부를 확인한 뒤 저장·결재는 직접 진행하세요.
